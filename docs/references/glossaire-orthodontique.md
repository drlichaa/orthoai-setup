# Glossaire orthodontique du cabinet

Vocabulaire à respecter dans les comptes rendus, courriers, DEP, fiches et écrans.
Termes exacts, orthographe française, sans abréviation non expliquée dans les documents patients.

## Numérotation dentaire (FDI)
- Permanentes : 11–18, 21–28, 31–38, 41–48 (quadrant puis dent ; 1 = haut droit, 2 = haut gauche,
  3 = bas gauche, 4 = bas droit). Temporaires : 51–55, 61–65, 71–75, 81–85.
- Écrire « la 12 », « les 13 et 23 », « les 18, 28, 38 et 48 (dents de sagesse) ».
- Denture temporaire / mixte / permanente.

## Diagnostic (structure du compte rendu)
- **Sens transversal** : articulé croisé (unilatéral droit / gauche, bilatéral), endoalvéolie,
  endognathie maxillaire, exoalvéolie, latérodéviation mandibulaire, RAS.
- **Sens vertical** : supraclusion (recouvrement augmenté), infraclusion, béance antérieure /
  latérale, normoclusion ; typologie hypodivergente / normodivergente / hyperdivergente.
- **Sens antéro-postérieur** : classe d'Angle molaire et canine, droite / gauche :
  classe I, classe II division 1, classe II division 2, classe III ; surplomb (en mm),
  occlusion inversée antérieure.
- **Classe squelettique** : classe I, II ou III squelettique ; rétrognathie / prognathie
  maxillaire ou mandibulaire, rétromandibulie, promandibulie.
- **Malpositions** : vestibuloversion, linguoversion, palatoversion, rotation (mésio- /
  disto-), ectopie, égression, ingression, diastème, inclusion, transposition.
- **Encombrement** : léger, modéré ou sévère (uniquement si précisé), arcade concernée ;
  DDM (dysharmonie dento-maxillaire), DDD (dysharmonie dento-dentaire, Bolton).
- **Anomalies de nombre / d'éruption** : agénésie, dent surnuméraire, dent incluse, dent
  retenue, extraction prévue.
- **Facteurs fonctionnels** : ventilation buccale, déglutition atypique (interposition
  linguale), succion (pouce, doigt, tétine), mastication unilatérale, phonation (sigmatisme).

## Appareils (noms du catalogue)
Disjoncteur, Quad Helix, Activateur, PUL (propulseur universel light), Masque de Delaire
(masque facial), Plaque (avec vérin), ELN (enveloppe linguale nocturne), bagues métalliques /
céramiques (multi-attaches), élastiques inter-maxillaires (Moose, Parrot, Rabbit, Ram, Walrus ;
force 1 / 2), tractions (TIM 2, TIM 3, TIM Rectangle, Criss-Cross), Carrière + gouttière
mandibulaire, gouttières d'alignement (aligneurs Spark™), stripping (IPR), mainteneur d'espace,
contention (fil collé et gouttière), OAM (orthèse d'avancée mandibulaire, apnées du sommeil).

## Fils et suivi
NiTi .012 → .019x.025, TMA .017x.025 / .019x.025, Acier .016 → .019x.025.
Séance : arc sup. / inf., chaînette sup. / inf., ressort ouvert / fermé, recollage (dent),
finitions, dépose.

## Corrections fréquentes de la reconnaissance vocale
« classe deux division un » → classe II division 1 · « a génésie » → agénésie ·
« bé ance » → béance · « dix-joncteur » → disjoncteur · « quad élix » → Quad Helix ·
« supra-clusion » → supraclusion · nombres dictés « un deux » → dent 12 selon le contexte.
En cas de doute : ne pas deviner, signaler dans « points à vérifier ».

## Ton des documents
- Patient / parents : phrases simples, sans jargon (« les dents du haut avancent »).
- Confrères : termes cliniques exacts, concis, courtois.
